# Reels ssenariylari — 4 hafta, 12 ta video

Haftasiga 3 ta, kameraga gapiriladigan format. Har bir ssenariyning o'z
manba kodi bor (`reels_01` … `reels_12`) — bio havolasini o'sha kod bilan
almashtirib qo'ysangiz, admin panel → Dashboard → **Trafik manbalari** →
*Reels bo'yicha* jadvalida qaysi video sotuv keltirgani ko'rinadi.

**Har bir videoning havolasi:**

```
https://t.me/santyxnarxbot?start=reels_01
```

Admin panel → Dashboard → Havola generatori shu havolani o'zi yasab beradi.
